# AeroVista FieldWatch

Passive field-mapping module for WiFi Pineapple Mark VII.

## Goal

FieldWatch turns the Mark VII into a lightweight wireless observability node:

- New SSID detection
- New client MAC detection
- First seen / last seen tracking
- Vendor lookup support
- JSON/CSV export
- Optional webhook alerts to NXCore or n8n

## Scope

Authorized wireless visibility, property auditing, lab monitoring, and defensive field mapping.

This project does not include deauth, spoofing, captive portals, credential capture, or offensive automation.
